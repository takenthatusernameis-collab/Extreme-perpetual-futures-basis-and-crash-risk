# Durable research state

- `agent_task_message.md`: authoritative next-worker task.
- `agent_handoff.md`: verified facts, blockers and next action.
- `universe_frontier.json`: descending market-cap candidate frontier and cursors; current rank is discovery-only.
- `hypothesis_registry.json`: frozen hypothesis IDs, anchor, status and artifact references.
- `run_manifest.json`: run and grid accounting.
- `grid_manifest_v1.json`: generated IDs and hashes.
- `workflow_run_diagnostics.jsonl`: generated by the scheduled controller after run collection.

These files are operational state, not substitutes for immutable evidence. Never invent metrics. Update atomically and record source/code/config hashes.
